# 🎮 Kora’s Adventure

**Kora’s Adventure** é um jogo de plataforma 2D em pixel art, desenvolvido com foco educativo.  
O jogador acompanha **Kora**, uma jovem aventureira curiosa e determinada, em uma jornada pelo mundo de **Arandora**, explorando quatro ilhas que representam as estações do ano.

O projeto busca unir **aprendizado, diversão e narrativa**, sendo adequado para todas as idades e especialmente voltado para uso escolar.

---

## 🌍 Sobre o Jogo

- 🎨 Estilo visual: **Pixel Art 2D**
- 🎮 Gênero: **Plataforma**
- 📚 Proposta: **Educativa**
- 👶 Classificação indicativa: **Livre**
- 🌱 Progressão natural de desafios
- 🏝️ Quatro ilhas temáticas (estações do ano)

---

## 🎮 Jogabilidade

O jogo utiliza mecânicas clássicas do gênero plataforma, com controles simples e intuitivos:

- Pular  
- Andar  
- Atacar  

A experiência foi pensada para ser acessível, fluida e fácil de aprender.
